# PyForge — Product Roadmap

Features prioritized and structured across three disciplined operational buckets:

---

## 1. Core (Solve Problems Faster)
High-impact developer ergonomics focused strictly on accelerating problem comprehension, code execution, and algorithmic mastery:
- **Custom Test Case Generator**: Input custom raw arguments into the console dock without modifying solution code.
- **Runtime & Memory Percentile**: Show user's execution time compared to benchmarks (e.g. `faster than 88% of submissions`).
- **Editor Keymaps**: VS Code, Vim, and Sublime Text keybinding profiles within Monaco Editor.
- **Instant Reset**: One-click restore to original challenge boilerplate with confirmation modal.
- **Offline Mode**: Full local PWA caching of challenges, starter templates, and test verification runner.

---

## 2. Power User (Productivity & Interview Prep)
Specialized capabilities for engineers on tight job-hunting timelines:
- **Company Tags**: Filter problems by frequency asked at Google, Amazon, Meta, Microsoft, Stripe, and Apple.
- **Timed Mock Assessments**: 45-minute timed simulation pairing 2 curated problems with a strict countdown timer.
- **Bookmarks & Custom Review Lists**: Save tricky problems to custom collections (`Needs Revision`, `Blind 75 Equivalent`, `System Prep`).
- **Multi-Language Expansion**: Bring the same 3-panel workspace experience to TypeScript, Go, and Rust.
- **Export & Sync**: Export solved solutions to a local GitHub repository (`pyforge-solutions`).

---

## 3. Experimental (Advanced AI & Collaboration)
Carefully bounded explorations that will be evaluated based on real developer usage patterns:
- **Socratic AI Nudges**: Step-by-step contextual hints powered by LLMs that guide algorithmic intuition without spoiling code.
- **Peer Solution Discussions**: Clean, GitHub-discussions-style threads indexed by Big-O time and space complexity.
- **Pair Programming Workspace**: Real-time collaborative editor session for peer mock interviews.
